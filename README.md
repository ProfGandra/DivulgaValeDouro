# DivulgaValeDouro

Portal de divulgação do universo literário ValeDouro.

## Publicação

Configure **Settings → Pages → Build and deployment → Deploy from a branch** e selecione **main / (root)**.

Site: https://profgandra.github.io/DivulgaValeDouro/

## Carta da Taverna Medieval

QR Code deve apontar para:

https://profgandra.github.io/DivulgaValeDouro/?origem=taverna#taverna

O parâmetro permite abrir uma mensagem específica para visitantes que receberam a carta. Não há analytics ou contador de acessos implementado nesta versão.

## Observações

- Sem dependências de build.
- A URL Kindle é oficial.
- O botão da edição física usa uma busca na Amazon até ser definido o link direto da UICLAP.
- Não gerar QR Code definitivo antes de habilitar e testar GitHub Pages.
